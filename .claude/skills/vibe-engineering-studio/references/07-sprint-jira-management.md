# 07 Sprint and Jira-Style Management

Use this file when managing multiple projects, sprint work, Jira activities, epics, stories, bugs, and daily engineering flow.

## Work item types
- Epic
- Story
- Task
- Bug
- Spike
- Tech debt
- Prompt experiment
- AI session review

## Sprint board columns
Use these columns in `SPRINT_BOARD.md`:
- Backlog
- Ready
- In Progress
- AI Coding
- Review
- Testing
- Done
- Blocked

## Story format
Each story should include:
- Title
- User role
- Goal
- Business value
- Acceptance criteria
- Technical notes
- Target files/modules
- AI prompt link/reference
- Test command

## Multi-project dashboard
For each active project track:
- Current sprint goal
- Active branch
- Last AI session
- Open bugs
- Token/cost status
- Next action
- Blockers
