# 02 Design and Architecture

Use this file to create architecture, UI, database, API, and security planning artifacts before coding.

## Design sequence
1. Product workflow map
2. User stories
3. Screen/page map
4. Component/module map
5. Data model
6. API contract
7. Security/privacy checklist
8. Test plan
9. Deployment plan

## Architecture output
Create `ARCHITECTURE.md` with:
- system overview
- frontend modules
- backend modules
- database schema summary
- integrations
- background jobs/queues if needed
- auth and permissions
- logging and observability
- deployment assumptions

## UI design output
Create `DESIGN_SYSTEM.md` with:
- layout principles
- core screens
- reusable components
- navigation model
- forms and validation
- empty/loading/error states
- accessibility checklist

## Database output
Create `DATABASE_DESIGN.md` with:
- entities
- relationships
- important fields
- indexes
- audit fields
- migration notes
- data retention/privacy notes

## API output
Create `API_CONTRACT.md` with:
- endpoints
- methods
- request/response examples
- auth requirement
- validation rules
- error format
