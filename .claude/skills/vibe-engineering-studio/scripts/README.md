# scripts/  — skill helper scripts

Small, skill-scoped scripts the `vibe-engineering-studio` skill can run
(e.g. a context-pack generator, a prompt-library indexer, a cost rollup).
Keep project runtime scripts (the IONOS tunnel etc.) at the repo-level
`scripts/` instead.

Each script should be self-contained and documented at the top with its
inputs/outputs. None added yet.
