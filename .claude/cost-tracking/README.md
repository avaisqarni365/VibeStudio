# cost-tracking/  — Cost Tracker module

Token + spend tracking across models and subscriptions. Files here are
periodic rollups / exports; the live source is `dev_prompt_history`
(per-call tokens, model, provider, duration).

**Files:**
- `YYYY-MM.md` — monthly summary (tokens + $ per model/provider/member/project)
- `budget.json` — caps + alert thresholds

```json
// budget.json
{
  "monthly_usd_cap": 200,
  "alert_at_percent": 80,
  "per_model": { "claude-opus-4-8": { "in_per_mtok": 0, "out_per_mtok": 0 } }
}
```

**Live (since 2026-06-01):** `budget.json` is real and served by
`GET /api/v1/dev-portal/ops/budget` (`getBudget()`). `usage.tsx` reads it for
per-model **$** rows, a total **Est. cost** card, and a **budget bar** (spend
vs `monthly_usd_cap`, amber/red past `alert_at_percent`). `per_model` keys are
substrings matched against the model id (first match wins); prices are USD per
1M tokens. Cache reads ≈0.1× input, writes ≈1.25×; local models = $0. Cache
tokens come from `dev_prompt_history.cache_read_tokens`/`cache_write_tokens`
(migration 083).

**Cost-per-feature ROI (A7):** `GET /projects/:projectId/cost-roi` joins spend to
`dev_tasks`/`dev_sprints` (per-task & per-sprint cost + cost-per-point); shown in
the Project page **Cost ROI** tab.

**Monthly rollups:** `YYYY-MM.md` exports are generated by `writeMonthlyRollup()`
via `POST /ops/cost-rollup {month}` (managers) or the **Monthly cost rollup** card
on `usage.tsx`. `GET /ops/cost-rollup?month=` computes a month + lists months with
usage. These `.md` files are regenerable exports — safe to delete/commit. All cost
math goes through the shared `_costEngine(budget)` (same prices as `usage.tsx`).
